# 개복치 신입사원 — 기획 & 개발 계획서

> 정장 입은 개복치 "복치"가 인턴으로 입사해 **회장**이 될 때까지 키우는 병맛 육성 게임.
> 복치는 **세상에서 가장 예민한 직장인**이라 사소한 일로 퇴사한다. 하지만 퇴사할수록 강해진다.

---

## 1. 자료조사 요약

### 1-1. 원작 「개복치 키우기 (Survive! Mola Mola)」 구조 분석
| 원작 요소 | 원작에서의 역할 | 우리 게임 대응 |
|---|---|---|
| 먹이 먹기 → 몸무게(kg) 증가 | 기본 성장 | **업무 처리 → 실적** 증가 |
| 크기 등급(아기 → 2.5톤) | 목표/진행도 | **직급**(인턴 → 회장) |
| 모험(도전) – 성공 시 큰 보상, 실패 시 사망 | 위험한 선택 | **프로젝트**(회식, 야근, PT발표…) |
| 같은 모험으로 죽을수록 성공률 증가 | 죽음 = 진행 | **내성**: 같은 이유로 퇴사할수록 해당 위험 감소 |
| 고유 사망 원인 발견 시 보너스 MP | 수집욕 | **퇴사 도감** + 신규 사유 보너스 퇴직금 |
| MP로 스킬(새 먹이/새 모험/먹이 수) | 영구 성장 | **퇴직금**으로 **자기계발** 업그레이드 |
| 거북이 피버 | 리듬 변화 | **월급날 피버**(황금 봉투 터치) |
| 시간 회복 행동력 | 페이싱 | **커피(☕)** 행동력 |

### 1-2. 방치/증분형 게임 페이싱 레퍼런스
- 첫 프레스티지(우리 게임의 "첫 의미 있는 업그레이드 사이클")는 **15~35분**이 적정, 늦으면 이탈.
- 각 단계(직급) 전환은 **3~5분의 능동 플레이**가 이상적.
- 리셋(퇴사)은 **손실이 아니라 보상**으로 느껴져야 함 → 퇴사 화면에서 "획득 퇴직금/신규 도감"을 크게 보여준다.
- 45~180분 구간은 "안정된 중반 + 리셋 보너스 누적" 구간 → 목표 플레이타임 2~3시간과 일치.

### 1-3. 웹/모바일 기술 조사
- PWA 설치 조건: `manifest`(name, icons 192/512, start_url, display) + HTTPS + 서비스워커(fetch 핸들러) 권장.
- iOS는 manifest 대신 `apple-touch-icon`, `apple-mobile-web-app-*` 메타 필요.
- 노치 대응: `viewport-fit=cover` + `env(safe-area-inset-*)`.

## 2. 게임 디자인

### 2-1. 핵심 루프
```
업무 터치(실적↑, 스트레스↑) ─┬─> 승진(직급↑, 보너스 퇴직금, 새 위험/콘텐츠 해금)
프로젝트 도전(큰 실적 or 퇴사) ┤
랜덤 이벤트 선택지 ───────────┤
                              └─> 퇴사! → 퇴사 카드(공유) → 퇴직금 + 도감 + 내성
                                         → 자기계발(영구 업그레이드) → 재입사(인턴부터)
```

### 2-2. 자원
| 자원 | 설명 | 생애 리셋 |
|---|---|---|
| 실적 | 업무/프로젝트로 획득, 승진 조건 | O |
| 스트레스 (0~100) | 업무/이벤트로 상승, 100이면 번아웃 퇴사 | O |
| 커피 ☕ | 프로젝트 도전에 소모, 시간 회복 | O (최대치는 업그레이드) |
| 퇴직금 💰 | 퇴사/승진/이벤트로 획득, 업그레이드 구매 | X (영구) |
| 도감/내성/엔딩 | 영구 기록 | X |

### 2-3. 직급 (9단계)
인턴 → 사원 → 대리 → 과장 → 차장 → 부장 → 이사 → 사장 → **회장(메인 엔딩)**
- 직급마다 새 업무 종류, 새 프로젝트, 새 이벤트, 새 퇴사 사유가 열림.

### 2-4. 퇴사(사망) 경로 — 총 120개 이상 목표
1. **프로젝트 실패** – 프로젝트별 2~3개 사유 중 랜덤.
2. **이벤트 선택지** – 처음엔 뭐가 위험한지 모름(병맛 포인트).
3. **함정 업무** – 터치하면 일정 확률로 퇴사(예: 전체답장 메일).
4. **번아웃** – 스트레스 100. 직급별로 다른 사유.
5. **돌봄 실수** – 너무 많이 쓰다듬기, 너무 오래 방치, 휴식 중 사고.
6. **히든** – 새벽 접속, 월요일, 시계 연타 등 특수 조건.

### 2-5. 내성
- 같은 사유로 퇴사한 횟수 n → 해당 위험 확률 × 0.5ⁿ.
- 프로젝트로 퇴사할 때마다 그 프로젝트 성공률 +10%p (최대 95%).

### 2-6. 자기계발(영구 업그레이드)
업무 숙련 / 멀티태스킹 / 업무 다양화 / 자동 업무(방치) / 멘탈 강화 / 기획력 / 커피 머신 / 처세술 / 낙하산(시작 직급↑)

### 2-7. 미니게임
- **타이밍 바**: 회식 건배, PT 발표 등 → 성공 구간 맞추면 성공률 보너스.
- **연타**: 야근, 엑셀 마감 등 → 제한시간 내 목표 횟수.

### 2-8. 엔딩 (5종)
| 엔딩 | 조건 |
|---|---|
| 👑 회장 취임 (메인) | 회장 달성 |
| 🍗 치킨집 사장님 | 누적 퇴사 30회 이후 등장하는 이벤트 수락 |
| 📹 구독자 100만 유튜버 | 생애를 넘어 '브이로그' 선택지 3회 |
| 🌊 바다로 돌아가다 (히든) | 부장 이상에서 수족관 워크숍 이벤트 특정 선택 |
| 💭 이 모든 건 꿈이었다 (진엔딩) | 메인 엔딩 + 도감 80% 이상 |

### 2-9. 목표 페이싱 (처음 하는 플레이어 기준)
| 구간 | 누적 시간 | 상태 |
|---|---|---|
| 첫 퇴사 | 1~3분 | 시스템 이해, 웃음 |
| 대리 첫 도달 | ~15분 | 업그레이드 몇 개 |
| 과장~차장 | 30~60분 | 프로젝트/내성 활용 |
| 부장~이사 | 60~120분 | 미니게임, 히든 탐색 |
| 회장(메인 엔딩) | 120~160분 | |
| 도감 완성/모든 엔딩 | +60분 이상 | |
→ `tools/balance-sim.js`로 시뮬레이션하여 검증.

## 2-10. 난이도 조정 (v2)
- 피드백: "병맛인 만큼 난이도가 있어야 한다" → 어려움을 기본 난이도로.
- 수치 상향: 업무당 스트레스 1.1→1.4, 회복 0.45→0.35/초, 휴식 회복 35→30·사고 5%→8%,
  함정 업무 10%→15%, 이벤트 간격 35~65→28~50초, 이벤트 위험 선택지 ×1.4,
  프로젝트 실패 시 퇴사 +12%p, 돌연 퇴사 2배, 미니게임 판정 축소/속도 증가.
- 신규 '돌발 상황'(실력으로 극복): 부장님 순찰 / 대표님 등장 / 정적 타임.
- 퇴사가 잦아진 만큼 퇴직금 단가를 낮추고 후반 직급 요구치를 올려 시간 유지.
- 시뮬레이션(봇) 결과: 회장 도달 약 100분 (직급당 10~15분), 회장까지 퇴사 약 54회, 초반 생애 평균 수명 약 20초.
  → 사람 기준 메인 엔딩 약 2.5~3시간 예상.

## 3. 기술 설계

### 3-1. 원칙
- **빌드 도구 없음**: 순수 HTML/CSS/JS. `index.html` 더블클릭으로도 실행.
  (ES 모듈은 file://에서 동작하지 않으므로 전역 네임스페이스 `G` + 일반 `<script>` 사용)
- 그래픽: 인라인 SVG 캐릭터 + CSS 애니메이션 + 이모지(외부 이미지 최소화).
- 사운드: WebAudio로 효과음 합성(음원 파일 없음).
- 저장: `localStorage` (버전 필드 + 마이그레이션).
- 모바일 우선 세로 레이아웃, PC에서는 중앙 폰 프레임 + 키보드 단축키.
- 게임 로직(`data/`, `systems/`)은 DOM 비의존 → Node에서 밸런스 시뮬레이션 가능.

### 3-2. 파일 구조
```
fish/
├─ index.html                 # 진입점, 스크립트 로드 순서 정의

├─ assets/icons/              # 앱 아이콘 (svg, 192, 512, maskable)

├─ js/

│  ├─ data/

│  │  ├─ minigames.js         # 타이밍/연타
│  │  └─ sharecard.js         # 퇴사 카드 이미지 생성 & 공유

```

### 3-3. 개발 순서
1. 기반: index/css/ns/util/storage
2. 데이터: 직급/업무/업그레이드/프로젝트/이벤트/퇴사(대량)/엔딩
3. 시스템: state/economy/rules
4. UI: 캐릭터/HUD/사무실/모달/미니게임/공유카드
5. 루프 & 오프라인 진행
6. PWA(manifest, sw, 아이콘)
7. 밸런스 시뮬레이션 → 수치 조정
8. 크롬에서 PC/모바일 해상도 실플레이 테스트 → 버그 수정
